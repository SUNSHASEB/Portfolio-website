A new themed event. Every single week.

The official All Elite Wrestling idle game by East Side Games. Players collect and upgrade the real roster, run shows like Dynamite, Rampage and Collision, and compete in limited-time events.

I joined to raise the UI bar: event UI and UX, community and chat, and the icon and identity systems.

02 The challenge

A lot on screen. A licensed brand.

01Density

Progression, timers, milestones and rewards, without burying the core idle loop.

02Cadence

A new event every week. Designs had to be templates, not one-offs.

03Brand fidelity

Every wrestler is a real person. Every logo and background needed AEW approval.

04Retention

Factions and chat had to make a single-player game feel social.

03 Live events UI & UX

Every week, a mini product.

Each event has an entry point, intro, themed venue, milestone track, leaderboards and rewards. I designed a modular framework so every week looks new but plays familiar.

04 UX decisions

Decisions that mattered.

01One-glance status

Time left, current milestone and unclaimed rewards on one HUD.

02Progressive disclosure

Rules and scoring one tap deep. The default view says what to do next.

03Reward transparency

Tracks preview every reward up front, answering feedback about opaque paywalls.

04Template-first

Figma components meant a new event could be themed in days, not weeks.

05 Wrestler identities

Every wrestler, instantly known.

Logotypes that turn each wrestler's real persona into the game's visual language, plus backgrounds behind their cards, matches and story moments. Approved by AEW and the talent.

06 Iconography

Readable at 24px.

One icon language for factions, match types, timers, rewards and the event economy. Hundreds of icons on a shared grid, stroke and silhouette system.
